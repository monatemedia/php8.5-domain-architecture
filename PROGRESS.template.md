# Progress Tracker — template
> Advanced Domain Architecture & Tactical DDD — the single place you record what you have done.

> **Copy this file to `PROGRESS.md` before you start.**
>
> ```bash
> cp PROGRESS.template.md PROGRESS.md
> ```
>
> `PROGRESS.md` is git-ignored, because it is yours: your ticks, your scores, your sticking points.
> This template is what the repository tracks, so the next person gets a clean one.

**How to use this file:** tick a box only when that piece is genuinely finished. For a lesson,
"finished" means you read the README, you *ran* every example and understood the output, you
completed the challenge without reading the solution first, and you scored above the quiz's
threshold.

Do not start a module until the one before it is fully ticked.

Each module ends with a **gate** in [`GATES.md`](GATES.md). Half of it covers the module you have
just finished; the other half reaches back to modules you finished a while ago. That second half
does the real work — a concept recalled once, then again three modules later, is held far longer
than one recalled twice in an afternoon. Take the gate with every other file shut.

> `php check.php` works out where you are automatically. It walks the lessons in order and stops
> at the first unsolved one. Use it to confirm what you tick off below.
